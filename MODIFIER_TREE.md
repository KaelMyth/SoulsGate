# Контракт дерева модификаторов (релиз 151)

Перед рефакторингом создана резервная ветка `backup/pre-mod-tree-rework-v150` от
`dd0dd383aefafac09d5bdbe1e8ed28ce3e15264f`.

## Правило носителя

Все модификаторы принадлежат ближайшему механическому предку в дереве.
Механические узлы: Клинки, Лазер, Дробь, Аура, Поглощение, Гравитация,
Фантом, Пробитие. Если такого предка нет, носитель — ядро (`root`).

- `Кинетический рывок → Клинки → Горение`: огненные **клинки**, не рывок.
- `Кинетический рывок → Молния`: электрическая цепь самого рывка.
- `Кинетический рывок → Лазер`: перед прыжком световой луч.
- `Кинетический рывок → Клинки → Горение → Мороз → Молния`:
  все три стихии и их реакции принадлежат **клинкам**.
- `Снаряд → Лазер → Поглощение`: попадание лазером **запускает**
  Поглощение, а не превращает весь снаряд в Поглощение.

`BuildGrid.modifiersFor(id).scopes` — единый результат маршрутизации
по носителям. `build_scopes.js::forCarrier(mods, kind)` выбирает
локальные стихийные свойства перед передачей в конкретный исполнитель.
Новые механики должны пользоваться этой маршрутизацией вместо
бесконтрольного чтения глобальных `mods.burn/frost/lightning`.

## Композиция рывка

Если на Кинетическом рывке одновременно Лазер, Молния и Клинки:
1. Молния вычисляет маршрут между врагами.
2. Лазер визуализирует текущий отрезок **до** начала движения по нему (0,12 с); затем герой проходит этот отрезок лазерным рывком за 0,035 с. Каждый прилёт запускает эффект Лазера, а Молния сохраняет урон своей цепочки.
3. После короткой фазы луча герой проходит этот отрезок.
4. Клинки выпускаются по пройденному пути, сохраняют наведение на врагов,
   независимо от стиля перемещения героя.
5. У каждого выпущенного клинка сохраняется его локальный набор стихий.
6. Множители на клинках увеличивают число клинков, а на ядре
   увеличивают параметры самого рывка.
7. При Лазере без Молнии луч предваряет один безопасный прыжок. При Лазере вместе с Молнией, но без доступных врагов, выполняется тот же одиночный лазерный рывок вместо обычного рывка.

Новые комбинации **не должны** отключать другие действующие ветки
одного корня только потому, что включился специальный режим перемещения.
