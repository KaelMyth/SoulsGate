# Запрос Графики → Моды: поле редкости у модов

**Что нужно.** В записи каждого мода в `config.mods` поле `rarity`: `'common' | 'rare' | 'legendary'`.
Если поля нет, считается `'common'`.

**Зачем.** Меню билда рисует плитку мода по редкости: обычные это камень, редкие это железо, легендарные это золото.
Сейчас, пока поля нет, Графика берёт редкость из своей таблицы в `ui_stone.js` (константа `RARITY`), вот она:

| Редкость | Моды |
|---|---|
| common | power, haste, x2, x3 |
| rare | burn, frost, pierce, shot |
| legendary | laser, blades, aura, phantom |

Вторичные ядра (`effect.secondary: true`, сейчас firedash и lightdash) редкостью не задаются: у каждого свой дизайн плитки.
Поменяйте расклад в таблице, как нужно по балансу; поле `rarity` в конфиге имеет приоритет над таблицей, и после его добавления таблицу Графика удалит.

**Что считается готовым.** У каждого обычного мода в конфиге есть `rarity`. Новые моды без поля рисуются как обычные (камень).
