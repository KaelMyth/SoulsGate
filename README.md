# Прототип · этап 1: каркас, стик, герой

Пустая арена со скалами. Герой бегает под пальцем, камера следует за ним, в углу кнопка ⚙ с отладочной панелью.
Это обычная статическая страница: ни сборки, ни установки, ни зависимостей.

## Как открыть на iPhone (выбранный способ: GitHub Pages)

Бесплатно, ссылка постоянная, открывается откуда угодно. Один раз настраивается, дальше обновление занимает минуту.
Минус: бесплатный GitHub публикует только **публичные** репозитории, то есть код и игру сможет открыть любой, у кого есть ссылка.
(Код страницы и так виден любому, кто открыл её адрес, поэтому для прототипа это не страшно.)

**Один раз:**

1. Зарегистрируйся на github.com (бесплатно).
2. Создай репозиторий: **New repository**, имя например `proto`, тип **Public**, **Create repository**.
3. На странице нового репозитория нажми **uploading an existing file** и перетащи туда **содержимое** этой папки:
   `index.html`, `styles.css`, папку `src`. Файлы должны лежать в корне репозитория, не внутри ещё одной папки. Жми **Commit changes**.
   Остальное (`tests`, `serve.js`, `package.json`) можно не загружать. Перетаскивать папки лучше из Chrome или Firefox.
4. **Settings → Pages**. В **Source** выбери **Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
5. Через 1–2 минуты на этой же странице появится ссылка вида `https://ТВОЁ-ИМЯ.github.io/proto/`. Открой её на iPhone.

**Обновить сборку:** снова загрузи файлы с теми же именами (они заменятся) и нажми Commit. Подожди 1–2 минуты, перезагрузи страницу.
Убедиться, что открылась новая версия, можно по подписи в панели ⚙: там написано, какая сборка (`этап 1 · сборка 1`).

Если интерфейс GitHub выглядит иначе, чем описано, пришли скриншот, подскажу.

**Запасной вариант, для быстрых правок дома:** запусти на компьютере `node serve.js` (нужен Node.js) или `python3 -m http.server 8080`
и открой на iPhone в той же Wi-Fi сети адрес из консоли (`serve.js` печатает его сам). Двойной щелчок по `index.html` не сработает:
браузеры не запускают ES-модули с диска. В этом случае страница покажет оранжевую плашку с объяснением.

## Перед тестом на телефоне

- **Добавь страницу на экран «Домой»** (Safari → «Поделиться» → «На экран Домой»). Игра откроется на весь экран без адресной строки.
- **Выключи режим энергосбережения.** В нём Safari обычно режет анимацию до 30 FPS, и замеры будут неправдой.
- Держи телефон вертикально. В горизонтальном положении появится подсказка перевернуть.

## Что проверить на этапе 1

1. Стик появляется под пальцем и не промахивается, герой послушно бегает.
2. Страница не прокручивается, не масштабируется двумя пальцами и двойным касанием, нет меню долгого нажатия.
3. Второй палец не мешает: пока держишь стик, касание другой рукой ничего не ломает.
4. Герой не проходит сквозь скалы и границы арены, а скользит вдоль них.
5. FPS в панели держится около 60. Нажми ⚙, посмотри строку `FPS ... мин ...`.
6. Выпускание стика видно в строке `события` панели (`stick:release`): на это событие на этапе 4 повесится блок.

## Отладочная панель (кнопка ⚙ справа сверху)

Показывает FPS и минимальный FPS, время кадра, число объектов в мире, состояние стика, последние события.
Игра при открытой панели не останавливается, ползунки действуют сразу:

| Ползунок | Что меняет |
|---|---|
| Скорость героя | единиц мира в секунду при полностью отклонённом стике |
| Время разгона и остановки | инерция героя, 0 = мгновенно |
| Радиус стика | на сколько пикселей можно уводить палец от точки касания |
| Мёртвая зона стика | доля радиуса, внутри которой стик считается нулевым |
| Обзор: ширина экрана в единицах | масштаб (насколько близко камера) |
| Плавность камеры | 0 = жёстко за героем |
| Чёткость (макс. DPR) | плотность пикселей: выше чётче, но тяжелее для телефона |

Кнопки: **Сбросить мин. FPS**, **Скопировать параметры** (выдаёт текст, который можно прислать Кодерсу), **Сбросить параметры**.
Подобранные значения запоминаются на телефоне. На компьютере панель открывается и клавишей `` ` ``, стик заменяет мышь.

## Для разработчика

```
index.html, styles.css
src/
  main.js              запуск
  game.js              сборка частей
  config/game.js       все числа игры (арена, герой, стик, камера, цвета)
  config/tunables.js   список ползунков панели
  core/                шина событий, цикл с фиксированным шагом, FPS, пул объектов
  input/stick.js       виртуальный стик
  world/               арена, герой, камера
  render/renderer.js   отрисовка Canvas 2D
  debug/               панель и сохранение ползунков
  platform/viewport.js безопасные зоны iPhone, блокировка жестов Safari
tests/                 npm test (нужен Node.js 20+, зависимостей нет)
```

- Новый ползунок: одна запись в `config/tunables.js`.
- Новая скала: одна запись в `arena.rocks` в `config/game.js`.
- Меняешь стартовые значения ползунков: подними `version` в `config/game.js`, иначе у тех, кто уже двигал ползунки, останутся старые.
- События: `stick:press` `{x, y, time}`, `stick:release` `{time, duration, dirX, dirY, mag, cancelled}`, `config:changed` `{path, value}`.
