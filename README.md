# Прототип · этап 2: автоатака и враги-касатели

Герой бегает под пальцем и сам стреляет по ближайшему врагу. Враги появляются за краем экрана, бегут к герою и бьют при касании.
У героя и врагов есть здоровье, врага убить можно, героя тоже (экран «Ты погиб» и кнопка «Заново»).
Это обычная статическая страница: ни сборки, ни установки, ни зависимостей.

## Как открыть на iPhone (выбранный способ: GitHub Pages)

Бесплатно, ссылка постоянная, открывается откуда угодно. Один раз настраивается, дальше обновление занимает минуту.
Минус: бесплатный GitHub публикует только **публичные** репозитории, то есть код и игру сможет открыть любой, у кого есть ссылка.
(Код страницы и так виден любому, кто открыл её адрес, поэтому для прототипа это не страшно.)

**Один раз:**

1. Зарегистрируйся на github.com (бесплатно).
2. Создай репозиторий: **New repository**, имя например `proto`, тип **Public**, **Create repository**.
3. На странице нового репозитория нажми **uploading an existing file** и перетащи туда **содержимое** этой папки:
   `index.html`, `styles.css`, папку `src`. Файлы должны лежать в корне репозитория, не внутри ещё одной папки. Жми **Commit changes**.
   Остальное (`tests`, `serve.js`, `package.json`) можно не загружать. Перетаскивать папки лучше из Chrome или Firefox.
4. **Settings → Pages**. В **Source** выбери **Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
5. Через 1–2 минуты на этой же странице появится ссылка вида `https://ТВОЁ-ИМЯ.github.io/proto/`. Открой её на iPhone.

**Обновить сборку:** снова загрузи `index.html`, `styles.css` и папку `src` целиком (файлы с теми же именами заменятся, новые добавятся) и нажми Commit. Подожди 1–2 минуты, перезагрузи страницу.
Убедиться, что открылась новая версия, можно по подписи в панели ⚙: там написано, какая сборка (`этап 2 · сборка 1`).

Если интерфейс GitHub выглядит иначе, чем описано, пришли скриншот, подскажу.

**Запасной вариант, для быстрых правок дома:** запусти на компьютере `node serve.js` (нужен Node.js) или `python3 -m http.server 8080`
и открой на iPhone в той же Wi-Fi сети адрес из консоли (`serve.js` печатает его сам). Двойной щелчок по `index.html` не сработает:
браузеры не запускают ES-модули с диска. В этом случае страница покажет оранжевую плашку с объяснением.

## Перед тестом на телефоне

- **Добавь страницу на экран «Домой»** (Safari → «Поделиться» → «На экран Домой»). Игра откроется на весь экран без адресной строки.
- **Выключи режим энергосбережения.** В нём Safari обычно режет анимацию до 30 FPS, и замеры будут неправдой.
- Держи телефон вертикально. В горизонтальном положении появится подсказка перевернуть.

## Что проверить на этапе 2

1. **Постоять и подвигаться.** Автоатака не пропускает цели: пока враг в кольце вокруг героя, герой стреляет. Оранжевое кольцо на враге показывает, в кого сейчас целится.
2. **Выбор цели понятен.** Всегда стреляет в ближайшего. Если кажется, что выбрал не того, напиши, при каких условиях.
3. **Урон от касания чувствуется.** При ударе герой мигает (это неуязвимость), слева полоска здоровья падает.
4. **Враги умирают, героя можно убить.** После смерти через секунду появляется экран «Ты погиб», кнопка «Заново» начинает новый забег.
5. **Нет рывков.** Метка FPS рядом с ⚙ должна держаться около 60, даже когда врагов много (потолок в панели: «Потолок живых врагов»).
6. Помимо этого: стик по-прежнему не промахивается, страница не прокручивается и не зумится.

Что **не** сделано намеренно: блока, парирования и рывка нет (этап 4), волн нет (этап 3), стрелков нет (этап 4), опыта и улучшений нет (этап 6).
Враги пока налипают друг на друга, когда приходят с одной стороны. Это поправим на этапе 3 вместе с оптимизацией для большой орды.

## Отладочная панель (кнопка ⚙ справа сверху)

Показывает FPS и минимальный FPS, время кадра, здоровье и убитых, число объектов (враги, снаряды, эффекты), состояние стика, последние события. FPS и минимум всегда видны рядом с кнопкой ⚙.
Игра при открытой панели не останавливается, ползунки действуют сразу:

| Ползунок | Что меняет |
|---|---|
| **Герой** | скорость, время разгона и остановки, здоровье (действует с новой жизни), неуязвимость после удара |
| **Автоатака** | дальность выбора цели, перезарядка, урон, скорость, дальность полёта и размер снаряда |
| **Враг-бегун** | здоровье (у новых врагов), скорость, урон при касании, пауза между ударами |
| **Появление врагов** | секунд между появлениями, потолок живых врагов |
| **Управление** | радиус стика, мёртвая зона стика |
| **Камера и экран** | обзор (масштаб), плавность камеры, чёткость (макс. DPR) |

Кнопки: **Сбросить мин. FPS**, **Скопировать параметры** (выдаёт текст, который можно прислать Кодерсу), **Сбросить параметры**.
Подобранные значения запоминаются на телефоне. На компьютере панель открывается и клавишей `` ` ``, стик заменяет мышь.

## Для разработчика

```
index.html, styles.css
src/
  main.js              запуск
  game.js              сборка частей, слои столкновений, перезапуск забега
  config/game.js       все числа игры (арена, герой, атака, снаряды, враги, спавн, цвета)
  config/tunables.js   список ползунков панели
  core/                шина событий, цикл с фиксированным шагом, FPS, пул, список+пул (entity-pool), столкновения
  input/stick.js       виртуальный стик
  systems/             combat (урон), autoattack (цель и выстрелы), spawner (появление врагов)
  world/               арена, герой, камера, враг, снаряд, эффект
  render/renderer.js   отрисовка Canvas 2D
  ui/                  экран смерти, помощник для DOM
  debug/               панель и сохранение ползунков
  platform/viewport.js безопасные зоны iPhone, блокировка жестов Safari
tests/                 npm test (нужен Node.js 20+, зависимостей нет)
```

- Новый ползунок: одна запись в `config/tunables.js`.
- Новая скала: одна запись в `arena.rocks` в `config/game.js`.
- Новый враг: запись в `enemies`, на неё указывает `spawn.enemy`. Новый снаряд: запись в `projectiles`, на неё указывает `attack.projectile`.
- Меняешь стартовые значения ползунков: подними `version` в `config/game.js`, иначе у тех, кто уже двигал ползунки, останутся старые.
- События: `stick:press` `{x, y, time}`, `stick:release` `{time, duration, dirX, dirY, mag, cancelled}`, `config:changed` `{path, value}`,
  `projectile:fired` `{projectile, target}`, `damage:dealt` `{target, targetKind, amount, source, hp}`, `enemy:killed` `{enemy, source}`,
  `hero:died` `{source}`, `run:restarted`.
- `hero:hit-incoming` `{amount, source, cancelled}` приходит ДО применения урона по герою: подписчик может уменьшить `amount` или поставить `cancelled = true`. На этапе 4 здесь встанут блок и парирование.
- Слои столкновений (`core/collision.js`): герой, враги, снаряды героя, снаряды врагов. Правила «кто с кем» объявлены в `game.js`.
