# Просмотрщик спрайтов

Отдельная страница для просмотра всех спрайтов из `assets/sprites/`. В игру не встроена и игру не трогает.

Открыть: `<адрес игры>/sprites/` (локально: `python3 -m http.server 8000` в корне репозитория, затем http://localhost:8000/sprites/).

- Спрайты сгруппированы по папкам `assets/sprites/<папка>/`.
- Кадры `имя-0.png`, `имя-1.png`, … в одной папке показываются как анимация (FPS настраивается).
- Масштаб без размытия, фон: шахматка / тёмный как в игре / светлый.
- Клик по карточке: крупный просмотр, размер, путь, кнопка «Копировать путь».
- «Открыть файлы» или перетаскивание: посмотреть свои PNG без коммита (файлы никуда не отправляются).

Список файлов берётся из `assets/sprites/manifest.json`. `tools/pixellab.mjs` обновляет его сам после генерации. Если кладёте файлы руками, выполните `node tools/sprites-manifest.mjs`.
